# RIDI

[Yan, Shan and Furukawa, *RIDI: Robust IMU Double Integration*, ECCV 2018](https://openaccess.thecvf.com/content_ECCV_2018/html/Hang_Yan_RIDI_Robust_IMU_ECCV_2018_paper.html). Authors: Hang Yan, Qi Shan, Yasutaka Furukawa. [Original MIT-licensed implementation](https://github.com/higerra/ridi_imu). IPB implements the mathematical method independently; it does not load executable sklearn pickles or claim original pretrained accuracy.

RIDI is a train-calibrated sequence method. It fits a placement RBF SVM and per-placement, per-axis epsilon-SVR to one-second, 200 Hz IMU histories in a gravity-stabilized IMU frame. Feature smoothing uses sigma 2 and target smoothing sigma 30. At inference, regressed velocity constrains a least-squares, piecewise-linear acceleration bias in the **device** frame, with knots every 50 samples and regularization 0.1. The corrected acceleration is integrated to velocity; the common predictor integrates it to position. No reference position or velocity is consulted during prediction. Rotation comes from the declared task orientation source.

`ridi.yaml` is the original flat-floor planar reference; `ridi_3d.yaml` additionally fits a genuine vertical SVR from native XYZ labels and solves the same device-frame correction in 3D. The latter is `3d_adapted`, not original-paper 3D reproduction. Reference orientation in the current profiles differs from the original device-orientation protocol and is privileged input. When a dataset has no placement annotation, a separately recorded unknown-placement regressor replaces the unavailable four-class labels; no placement is fabricated.

The original implementation asynchronously corrects overlapping past histories. IPB uses bounded offline 1,000-sample correction blocks and carries velocity between them; this changes the update schedule and can use later cues within a block. Predictions are reduced to the shared evaluation grid before common integration. The paper's original zero initial velocity assumption is retained. Fixed C/epsilon in the unified recipe replace its per-placement cross-validation; fidelity therefore concerns the scientific method, not numerical identity to every original experiment.

At most 20,000 train windows are sampled **before** allocating the dense 1,200-dimensional features. Each train sequence contributes at least one window, with the chosen benchmark seed recorded. The cap, placement coverage and fitted-window count belong in every result. sklearn is needed only during calibration; checkpoints contain numeric support vectors, coefficients and intercepts as tensors, and prediction evaluates the RBF kernels independently. RIDI does not claim neural optimizer updates, common learning-rate sensitivity or GPU acceleration for its fitting stage.

Tests cover a rotating device-frame bias with a real vertical component, train-only calibration, RBF equivalence to the fitting library, bounded train sampling, no GT motion access at inference and exact tensor-only checkpoint reload.
