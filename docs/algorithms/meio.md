# MEIO-Net

[Sun et al., *MEIO-Net: A Motion-Aware Early-Exit Inertial Odometry Network for Efficient Pedestrian Dead Reckoning (PDR)*, IEEE Internet of Things Journal 13(3), 4142–4152 (2026)](https://ieeexplore.ieee.org/document/11251007), DOI 10.1109/JIOT.2025.3633690. The IEEE-deposited [DOI metadata](https://api.crossref.org/works/10.1109/JIOT.2025.3633690) lists Xuehang Sun, You Li, Yan Wang, Hongji Yan, Xuanxuan Zhang, Sikang Liu, Xueli Guo and Zhichao Wen. Xuanxuan Zhang is a different author from the owner's excluded Shanshan Zhang.

**Fidelity: paper-core partial reconstruction, not a complete official network migration.** The [official GPLv3 repository](https://github.com/SunXuehang/MEIO-Net) publishes training wrappers and example configurations but omits the imported `NeuralNetwork/EarlyExit/EarlyExitDense.py`. Its README and executable example also disagree on input length and feature width. The IPB configuration follows the `EarlyExitPDRModule.py` example: 200 samples, patch 10, feature width 512, six ResMLP layers, expansion two and dropout 0.5. Mean-pooling two-layer regression heads predict three-dimensional displacement and one isotropic log standard deviation, matching the released `[3,1]` declaration. The common `logstd` output broadcasts this scalar to XYZ; it does not invent three independent uncertainties.

The independently written loss follows the [released training specification](https://github.com/SunXuehang/MEIO-Net/blob/master/EarlyExitPDRModule.py): all exits train jointly; normalized depth powers weight MSE and the covariance entropy term separately. The Mahalanobis residual is not multiplied by the covariance weight. Reduction remains a **mean** across exits. The first ten epochs optimize weighted MSE; later epochs optimize weighted NLL, with an optional linear blend. Zero warmup means an instantaneous switch, explicitly fixing the wrapper's division by zero. The default weighted NLL remains unclamped as released; any configured log-sigma floor is a declared numerical adaptation. Post-switch behavior and covariance gradients require separate scientific tests, not just an epoch-one training smoke.

At inference, accepted samples leave the active batch immediately, so deeper layers do not run for those samples. Exit choice uses only predicted uncertainty, never GT motion. A scalar per-axis displacement variance threshold of 1e-3 m² is the declared interpretation of the released `noise_variance`; the omitted network prevents verifying its exact rule. Head placement after each ResMLP layer, independent head parameters and affine layout are reconstruction assumptions. A full-depth flag is available as a diagnostic reference, not a separate algorithm. Any threshold tuning must use train/validation only. IPB validation evaluates the actually selected exit, whereas the released wrapper reports all exits and highlights the last one; numerical original validation equivalence is not claimed.

The current profile uses the common gravity-world IMU and displacement task with reference orientation. The official data reader is absent, so this frame protocol is a declared benchmark adaptation and privileged orientation must be reported. The method predicts genuine XYZ; it does not pad a planar output. Tests check phase math, exit weighting, covariance/Z gradients, masks, actual reduced-depth computation and exact reload. Code readiness does not imply CPU acceptance or original-paper accuracy reproduction.
