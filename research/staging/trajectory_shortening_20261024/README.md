## 原因分解：2026-10-25 Agent 只读结果

2026-11-08 更新见 [敏感性分析记录](cause_sensitivity_20261108.json)：同口径单元由 220 增至
336，`plr_oracle` 中位数 0.9132，低方向误差组 `speed_ratio` 中位数 0.9297。
总体速度/方向相关为 −0.9245；去除方向误差 ≥45° 的 19 个单元后为 −0.3802。
112 个 profile/dataset 组内去均值后相关为 −0.9629；分层及去均值仍属描述性分析，不能证明因果。
严重失效单元影响总体相关，普通单元的幅值偏差仍需独立解释。
训练集与测试集预测差异同时混合数据和模式效应，不能单独用来排除 Dropout。

用户提出的核心问题是“为什么会缩短”，而不是强行把长度乘回 1。
[cause_decomposition.py](cause_decomposition.py) 在 Agent 上读取 519 个已完成的人体 XYZ 可训练单元，
并在其中 220 个 T200、`avg_velocity`、`reference_oracle` 单元上分解参考协议、模型幅值、方向误差和训练/测试模式差异。
完整小收据见 [cause_observation_20261025.json](cause_observation_20261025.json)，远端执行叶和源码绑定写在其中。

| 可能原因 | 远端观察 | 当前判断 |
|---|---|---|
| 1 秒参考采样/Oracle 平滑 | `oracle_ratio` 中位数 **0.9808** | 只解释约 2% 的中位差异，不能解释主要缩短 |
| 模型输出幅值低估 | `plr_oracle` 中位数 **0.9164**；`speed_ratio` 中位数 **0.9246** | 主要现象在模型输出中已经存在 |
| 纯方向错误导致向量相消 | 方向误差小于 20° 的 192 个单元中，`speed_ratio` 中位数 **0.9324**，speed/along bias 均为负 | 存在独立的径向幅值偏差；高方向误差尾部会进一步放大缩短，14 个单元中位 `speed_ratio=0.0190` |
| Dropout 或 train/eval 模式 | train/test `speed_ratio` 差的中位数约 **3.4×10⁻⁶** | 数据和模式效应混合，不能据此排除 Dropout；见下方同窗对照 |

`speed_ratio` 与方向误差的相关系数为 **−0.946**，描述两者共同变化，不能证明方向不确定性造成塌缩；低方向误差分层仍有约 6.8% 的中位速度低估，因此不能把全部现象归结为方向相消。`plr_oracle` 与 `speed_ratio` 的相关系数为 **0.998**，支持“轨迹变短主要来自输出速度幅值变小”。

这些数字是已观察算法/来源上的条件性证据，不是随机化因果效应。目标和损失本身在正式矩阵中与架构绑定，不能直接比较后称为原因。下一步按 [cause experiment plan](cause_experiment_plan.json) 做固定架构、固定数据、固定 seed 的干预：向量 MSE 对比幅值+方向损失，`avg_velocity` 对比 `velocity_at_end`，并保留 validation-only 标量 gain 作为控制。只有 ATE、10 秒 RTE 和速度/方向误差共同不恶化，才接受对应机制。

## 2026-11-08：初速度边界与可辨识性

[初速度诊断记录](velocity_state_observation_20261108.json) 覆盖当前 RIDI 全部 45 条训练录制、
8 个既有 group、720 个窗口。每条固定选 16 个非重叠有效运动窗；不读取 val/test，不更新权重，
在 Agent 只用两个 CPU 线程。初速度全部由相邻参考位置中心差分得到，属于特权信息。
解析测试验证匀加速积分与恒定速度变换；源码见 [velocity_state_probe.py](velocity_state_probe.py)。

下表先在各录制计算指标，再取 45 条录制的中位数。相对 L2 为向量误差的 Frobenius 范数除以
目标范数；幅值比为窗口速度模长之和的比值，均不等于轨迹 PLR。

| 训练窗诊断 | 速度幅值比 | 向量相对 L2 |
| --- | ---: | ---: |
| 零初速 + IMU 积分 | 0.2650 | 0.9944 |
| 参考初速 + IMU 积分 | 1.0285 | 0.1332 |
| 录制内错配初速 + IMU 积分 | 1.0327 | 1.7154 |
| 仅保留参考初速 | 1.0092 | 0.2596 |
| 原 checkpoint / seed1735231569 | 0.9056 | 0.2150 |
| 原 checkpoint / seed843628571 | 0.9766 | 0.1322 |
| 原 checkpoint / seed951150512 | 0.9298 | 0.2375 |

参考初速加积分在 45/45 条录制上分别优于零初速、错配初速和仅初速三个控制。
这支持边界状态信息的重要性，也保留了反证：一个原 checkpoint 已有相近的误差，
参考初速加积分不是最优误差下界；错配初速的幅值比接近 1，方向/向量误差却很大。

把参考位置改成 `p'(t)=p(t)+c·(t-t0)` 后，45 条录制的 IMU 输入全部逐元素不变，
目标速度增加 `c`。这是构造的 Galilean 可辨识性检查，不能当作真实数据歧义的发生比例。
向量 MSE 的理想条件均值满足 `||E[V|X]|| ≤ E[||V|| | X]`；残余方向歧义可能产生收缩，
仅有同向速度大小不确定性并不必然产生该差距。有限模型、优化与正则化也可能造成额外偏差。
因此尚不能把已有缩短主因归给初速度缺失，后续仍需固定网络/预算的状态和损失干预。
可部署候选只能使用估计状态；参考初速不得进入普通算法的测试输入。

## 2026-11-08：幅值、方向与标量增益的目标不同

[径向损失记录](radial_loss_observation_20261108.json) 使用相同三个已完成 checkpoint，
在 45 条训练录制的 720 个窗口拟合两种标量，再固定用于 4 条验证录制的 64 个窗口。
训练/验证 group 不重叠；验证只有一个既有 group，且曾用于原 checkpoint 选择。
本轮不读 test、不更新模型；这是窗口诊断，不能当作独立测试或轨迹精度验收。

设预测为 `p=r·u`、目标模长为 `s`、夹角为 `θ`，则向量平方误差恰好为
`(r-s)² + 2rs(1-cosθ)`。固定预测方向、使用单个标签时的非负最优幅值是
`max(0,s·cosθ)`，并不总是 `s`。这是几何控制，不能当作网络已学到条件均值的证据。

| seed | 验证原始相对 L2 | 训练拟合向量 MSE 增益后 | 训练拟合模长和增益后 |
| --- | ---: | ---: | ---: |
| 1735231569 | 0.31096 | 0.29869 | 0.29854 |
| 843628571 | 0.23244 | 0.23210 | 0.23249 |
| 951150512 | 0.31765 | 0.31714 | 0.32034 |

向量 MSE 增益为 `max(0, Σp·y/Σp·p)`，模长和增益为 `Σ||y||/Σ||p||`。
前者在验证上分别降低误差约 3.95%、0.15%、0.16%；后者使两个 seed 的误差增加。
两种增益的差异也受窗口权重及局部高估/低估混合影响，不能单凭它归因于方向不确定性。
这些标量只是控制，不是新定位方法；本轮没有验证轨迹 ATE/RTE 或 P95 风险。

低方向误差 `<20°` 的验证窗中，`r-s·cosθ` 均值分别为 −0.140、−0.037、−0.057 m/s。
这说明这些窗口的幅值还低于标签沿预测方向的投影，不能把全部偏小解释为方向投影的最优收缩。
验证中 `s≥1.2 m/s` 的 37 个窗口，三 seed 的幅值比分别为 0.847、0.932、0.884；
其他速度段存在高估反例，当前结果不支持“一律扩大”或“误差随速度单调变化”。

下一项受控训练需同时检查：普通方向窗的幅值低估是否来自优化/正则化，以及有方向歧义时
额外幅值损失是否迫使输出过长。固定架构和预算、等参数控制及 ATE/RTE 验证仍不可省略。

## 2026-11-08：动态变化分层复核

[动态分层记录](dynamic_lag_observation_20261108.json) 对同一 `ronin_resnet18_3d` 的三个已完成

参考速度变化的四分位边界为 0.18029、0.29627、0.47925 m/s。分层标签只用于诊断，未作为输入
特征或校正目标，也没有优化更新和测试集访问。

四个动态变化区间的速度比在三个 seed 间没有稳定的单调方向。训练端的整体速度比为 0.8964、
0.9733、0.9364，验证端为 0.8628、0.9635、0.9242；验证分层速度比分别为
`[0.8455, 0.8932, 0.8784, 0.8492]`、`[0.9145, 1.0068, 0.9835, 0.9629]` 和

部署，也不能用统一放大或动态分层本身宣称定位改进。

## 2026-11-10：窗口改善不能代替完整轨迹验收

ATE 未做对齐；另行保存的 aligned ATE 只允许刚体旋转和平移，不拟合尺度。

| --- | ---: | ---: | ---: | ---: |

这项只读控制尚不能区分优化、正则化、状态信息和方向不确定性的因果贡献，也不证明新的定位方法。
后续固定预算的状态/损失干预仍需独立身份和正式资源交接；GPU 干预与新网络 pilot 保持未启用。

## 2026-11-11：冻结特征后的回归层干预

[运行前固定的设置](head_intervention_plan.json) 和 [干预记录](head_intervention_observation_20261111.json)
比较原回归层、原向量 MSE 继续优化、增加幅值平方误差和截断最小二乘四组。三个原 checkpoint
的特征、BN 和 Dropout 关闭后的推理方式保持固定，只拟合 1,539 个线性回归层参数。
两组 AdamW 使用相同初始回归层、完整 720 训练窗、学习率 0.001、零 weight decay 和 256 步；
最终步数在运行前选定，未按验证表现挑选。数据为 45 条训练录制/8 个 group 与四条验证录制/1 个
不重叠 group；完整验证使用原生轨迹重建，包括静止段。全程只用两个 CPU 线程，不保存权重。

| seed | 原始 ATE / m | 原 MSE 优化后 ATE / m | 加幅值项后 ATE / m | 原始 PLR | 原 MSE 优化后 PLR |
| --- | ---: | ---: | ---: | ---: | ---: |
| 1735231569 | 4.9766 | 4.8388 | 4.7535 | 0.8836 | 0.9693 |
| 843628571 | 1.9769 | 1.7296 | 1.7392 | 0.9691 | 0.9866 |
| 951150512 | 4.7189 | 4.0348 | 4.2036 | 0.9235 | 0.9531 |

以上是每个 seed 在四条验证录制上的指标中位数。保持 MSE 不变，ATE 中位数分别下降 2.77%、
12.51%、14.50%，10s RTE 与位置误差 P95 中位数也在三个 seed 上下降。这表明所选冻结特征中
有可通过重新拟合回归层利用的信息，当前缩短并非全部由原 MSE 的不可避免幅值收缩解释。
加入幅值项虽进一步改善 PLR 和 10s RTE，中位 ATE 相对原 MSE 优化组在两个 seed 上反而增加。

截断最小二乘使训练相对向量误差从 0.233/0.152/0.250 降至 0.125/0.100/0.146，训练幅值比均
超过 0.988；但验证 ATE 在一个 seed、10s RTE 在两个 seed 上变差。该求解固定 `rcond=1e-6`，
513 个设计列仅保留 347/359/334 个数值方向；不能称为无截断的精确全局解或通用修复。

原 MSE 优化组仍有 3/12 个录制/seed 配对的 ATE 恶化，不能按中位数宣称所有录制安全改善。
而且本轮关闭 Dropout、均匀抽取每条录制的窗口、只训练回归层，与原完整训练的有效目标和约束
不同，尚不能把偏差单独归因于优化未收敛、正则化或采样权重。验证已用于原 checkpoint 选择，
也不是独立测试集。下一步应固定其余因素，分别区分采样权重、Dropout 与回归层优化的贡献，
再检查可部署的历史速度状态；GPU 完整干预计划和新网络 pilot 仍保持未启用。

## 历史快照：981 completed（保留原始口径）

本节及下方 SAGE-IO 是本轮较早的记录；当前统计与区间以上方 999-cell 分组分析及
Agent 定时刷新为准。SAGE-IO 保留为未执行草稿，当前推进的独立候选为 Coherent Spectral IO。

远端正式矩阵观察到 981 个已完成主 `test` split 的单元。以指标文档定义的
`plr = L_1s(prediction) / L_1s(reference)` 计算：

| 分层 | 单元数 | `plr < 1` | 中位数 PLR | 解释 |
|---|---:|---:|---:|---|
| 全部已完成主 test | 981 | 850（86.65%） | 0.8506 | 混合了同域、跨域、test-only 和不同输入契约 |
| 人体同域数据（RIDI/RoNIN/OxIOD/IDOL/IMUNet/TLIO/RNIN） | 405 | 392（96.79%） | 0.9084 | 当前最强的条件性证据 |
| UAV/机器人及其他 test-only | 576 | 458（79.51%） | 0.4267 | 域外参考和 checkpoint 迁移不能并入人体主结论 |
| 同一 profile/dataset 的配对组 | 290 组 | 86.21% 的组均值 `< 1` | — | 其中 256 组拥有至少三个 seed |

这已经足以把“同域人体结果经常出现长度变短”列为可复核现象，但还不足以写成“所有算法都如此”或“90% 普遍规律”。单元共享算法、数据集和序列，不能把 981 个单元当作 981 个独立受试者；当前汇总也还没有置信区间、逐序列 group bootstrap 或预注册的效应阈值。

更关键的是指标分解恒等式：

```text
plr_dense = oracle_ratio × plr_oracle
```

`oracle_ratio` 是窗口平均速度和 1 秒折线采样带来的协议平滑效应，`plr_oracle` 才更接近模型输出幅度效应。因此只把 `plr` 拉回 1 不能证明定位更好。已有结果也包含 seed、域外和算法级反例；本目录的 `claims_proven` 保持为空。

## 第一性原理问题

我们真正要解决的是：在固定 IMU 窗口、训练预算和推理预算下，模型是否系统性低估了速度幅度，导致累计位移偏差；如果存在，这个偏差能否在未见录制上降低 ATE/RTE，而不是只让 PLR 更接近 1。

因此研究顺序固定为：

1. 用 `plr_oracle`、`oracle_ratio`、`speed_ratio`、`along_bias` 和方向误差区分协议平滑、幅度误差和方向错误。
2. 按录制分组、按 seed 配对，使用 group bootstrap/置换检验；不把模型 profile 当作独立样本。
3. 先与恒等映射、一个全局 gain、固定因果滤波和固定 stride 比较。
4. 只有在 ATE/RTE 或固定时域漂移同时改善时，才保留可学习模块；只改善 PLR 就停止。
5. 对保留的模块使用新 profile、新 recipe、新 coverage 身份，不能回填当前正式结果。

## 历史 SAGE-IO 草稿（未执行）

`SAGE-IO`（Scale-Aware Gated Estimator for Inertial Odometry）是一个保底候选，组合了成熟的多尺度残差时序算子和针对当前现象的幅度/方向解耦读出：

- `MultiScaleTemporalBlock`：三个 1D depthwise temporal branches（kernel/dilation 为 3/1、7/2、15/4），用残差和输入门控融合。它借鉴 ResNet/ConvNeXt/TCN/MS-Temba 的可解释时序归纳偏置，但不是任一论文的完整复现。
- `ScaleGuardHead`：把窗口速度分解为单位方向、正速度幅度和有界 gain；gain 零初始化，初始行为接近普通速度头，避免一开始强行放大。
- `scale_guard_loss`：在原向量损失之外，可在新 recipe 中加入幅度 Smooth-L1 和非零目标方向损失。该辅助损失只属于新 recipe，不能混入冻结矩阵。

候选输入仍是 `B×6×200`、200 Hz、`[gyro_xyz, acc_xyz]`，输出是窗口平均 XYZ 速度。`ScaleGuardHead` 不读取 test 标签、历史窗口或参考轨迹；训练外的轨迹长度诊断只读结果文件。

候选的最小 pilot 是 `ronin_resnet18_3d`/`rio_3d` 对照，在 RIDI、RoNIN、IDOL 三个来源和三个固定 seed 上运行新 profile。先做 CPU/native lifecycle 和单卡容量，再决定是否启动 27 个候选单元。未通过下列任一条件就停止：

- PLR 接近 1 但 ATE/RTE 不改善；
- 一个全局 gain 或固定因果规则同样有效；
- 只在单一来源、单一 seed 或 privileged reference track 有效；
- 方向误差、`train_eval_gap` 或跨域尾部风险恶化；
- 模块收益来自改变数据划分、窗口、AMP、checkpoint 或 test 拟合。

代码见 `scale_guard.py`，静态契约见 `test_scale_guard.py`。当前状态是 `proposal_only`，尚未 import、训练、容量验收或注册。
